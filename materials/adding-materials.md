## PDF 文件

主页仅提供“阅读讲义”入口，不展示 PDF 下载链接。同步会递归跳过所有 PDF（扩展名不区分大小写），原始 PDF 仅保留在本地；尚未讲授的章节继续保留文件，但不显示阅读链接。

## 添加新课程

在 `materials/` 下建立新课程的文件夹并上传 Markdown 文件，然后在根目录的 `materials.json` 中，向 `courses` 数组追加一门课程：

```json
{
  "id": "new-course",
  "title": "新课程名称",
  "description": "课程的简短介绍。",
  "materials": [
    {
      "number": 0,
      "title": "绪论",
      "file": "materials/new-course/00-introduction.md"
    }
  ]
}
```

不同课程之间用逗号分隔，最后一项后面不加逗号。`id` 应保持唯一。保存发布后，新课程会自动显示在主页，“更多课程”区域也会继续保留。

## 链接与图片

在讲义中使用相对于当前文件的路径：

```markdown
[下一章](中心力场.md)
[另一章的某一节](中心力场.md#某一节的标题)
![示意图](images/figure.png)
```

`materials/` 内的 Markdown 链接会打开在线阅读页面；图片会使用原文件。PDF 不纳入网站上传范围。上传图片时，请保持文件夹和路径一致。

## 分享阅读链接

例如，“绪论”的阅读链接是：

```text
https://phyytang.github.io/?note=materials/Mechanics/绪论.md
```

Markdown 文件即使没有列入课程目录，也可以通过这样的链接打开。中文或含空格的文件名需要进行 URL 编码，主页自动生成的链接会完成编码。

## 编写数学公式

行内公式使用 `$ ... $`，独立公式使用 `$$ ... $$`。例如：

```markdown
行内公式：$x_i^2$。

$$
\sum_{i=1}^{n} x_i^2
$$
```

公式由 KaTeX 排版，代码块内的公式会保留为代码。完整 LaTeX 文档和 TikZ 图不能直接编译，可以上传对应图片；PDF 仅在本地保留。

可以打开[中文 Markdown 排版示例](preview.md)，查看文字、公式与表格的实际效果。
