# Markdown 排版示例

这是一份示例文档，用于展示讲义的在线阅读效果。课程目录中的每个章节都可以链接到类似的 Markdown 文件。

## 文字与结构

可以使用**加粗**、*强调*、标题、编号列表与引用来组织内容。

> Markdown 文件保存讲义正文，网页提供适合阅读的排版。

1. 从课程目录选择一个章节。
2. 阅读讲义正文与数学公式。
3. 使用顶部的返回链接，回到课程目录。

## 数学公式

行内公式使用单个美元符号，例如 $e^{i\pi}+1=0$ 或 $a_{ij}b^{jk}=\delta_i^k$。

独立公式使用两个美元符号：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x=\sqrt{\pi}.
$$

代码块会保留原始公式：

```latex
行内公式：$e^{i\pi}+1=0$

$$
\int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x=\sqrt{\pi}.
$$
```
